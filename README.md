# Minimal Viable Classroom

An intentional classroom that holds only what serves the lesson, and a launchpad for learning at nearby field sites. The project began with teaching in a shipping-container classroom and grew into a mini action plan for an IB school, written for IBECLP 1 (IB Educator Certificate in Leadership Practice, Western University, Fall 2026).

The frame is "Where there is no ___", after David Werner's *Where There Is No Doctor*: the room runs from where there is no power to the highest tech, but nothing goes on a table unless it serves that lesson.
